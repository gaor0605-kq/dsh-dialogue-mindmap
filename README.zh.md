# dsh-dialogue-mindmap

[English](README.md) | 中文

一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（`dsh`）Web 界面插件：在会话的「对话」标签右侧增加一个「画布」视图，把会话的每一轮画成思维导图里的一个节点，并且可以从任意节点继续追问拓展子节点——都在同一个会话里进行，不会新建会话。

## 功能

- **画布标签**：位于「对话」标签右侧，点击即可在同一会话的两种视图间切换。切到画布时，下方输入框会隐藏，画布撑满剩余高度。
- **每轮一个节点**：从左到右排成一棵树。第一轮是根节点；新的一轮默认挂在上一轮下面。
- **从任意节点拓展**：选中节点，在右侧详情栏输入追问，点按钮（或 Ctrl+Enter）发送。消息会发到当前会话，开头附带对所选轮次的简短引用，得到的新一轮会挂在该节点下面。回答到达之前会显示一个虚线的「等待回答…」占位节点。
- **详情栏**：点击节点后，右侧显示完整的问题和可滚动的完整回答，以及切回「对话」视图的按钮和拓展输入框。拖动详情栏左边缘可调整宽度（双击边缘恢复默认），宽度会被记住。
- **平移和缩放**：在空白处拖动可平移；鼠标滚轮以光标为中心缩放（25%～250%）；右下角有缩小 / 复位 / 放大按钮。

## 安装

```sh
dsh plugin add dsh-dialogue-mindmap
```

安装后刷新 Web 界面，打开任意会话，「对话」旁边就会出现「画布」标签。

## 已知限制

- 节点之间的父子关系保存在浏览器的 `localStorage` 里，按会话分别存放。不会在不同浏览器或设备之间同步；清除网站数据后，布局会退回成一条直线。
- 因为拓展发生在同一个会话里，模型仍然能看到完整的对话历史；开头的引用只是告诉它这次追问是基于哪一轮。
- 详情栏中的完整问答取自「对话」视图里已经加载的轮次。很早的轮次如果还没加载，会显示截断的摘要——在「对话」视图里往上滚一次即可加载。
- 隐藏输入框依赖 Web 界面的 `data-composer-seat` 属性，宿主界面更新后可能需要适配。

## 环境要求

DeepSeek Harness Web 界面（在 dsh 0.2.1-rc.5 上测试过）。插件只有前端部分，没有宿主端依赖。
